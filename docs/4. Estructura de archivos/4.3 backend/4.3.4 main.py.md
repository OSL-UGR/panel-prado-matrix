Por último el archivo incluye la configuración del "middleware de CORS". Esta política de seguridad es fundamental, ya que le otorga permisos explícitos a nuestro frontend en React para que pueda comunicarse con el backend y ejecutar métodos HTTP sin ser bloqueado por el navegador.

```python
app.add_middleware(
	CORSMiddleware, # Para que React (Front) se pueda comunicar con FastAPI (Backend)
	allow_origins=[settings.FRONTEND_URL], # Ponemos la url de nuestro Front
	allow_credentials=True,
	allow_methods=["GET", "POST", "PUT", "DELETE", "OPTIONS"], # Permitimos las operaciones necesarias
	allow_headers=["Content-Type", "Authorization"],
)
```

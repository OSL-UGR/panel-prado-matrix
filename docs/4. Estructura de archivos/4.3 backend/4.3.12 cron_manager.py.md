
Este archivo, ubicado en `services/cron_manager.py` es el encargado de ejecutar un cron temporal en segundo plano utilizando la librería `APScheduler`.

Su objetivo es vigilar constantemente el reloj para automatizar el envío de mensajes programados, aplicar restricciones de los horarios de uso y realizar tareas de mantenimiento en la base de datos.

A continuación se muestra el listado de tareas programadas:

**`verificador_horarios()`**

- Se ejecuta en el minuto 0 de cada hora. Lee el día y hora actual, consulta la matrix 7x24 de horarios y manda la petición a Matrix para abrir o cerrar el chat según lo configurado.

**`procesador_mensajes_programados()`**

- Se ejecuta automáticamente cada minuto. Busca en la base de datos todos los mensajes programados en estado de "pendiente" cuya fecha de envío haya llegado o se haya sobrepasado. Una vez identificados los lanza hacia Matrix realizando una petición y actualizando su estado en la bd a "enviado" o "fallido".

**`limpiador_historial_avisos()`**

- Se ejecuta todos los días a las 3:00 AM. Elimina permanente de la bd los mensajes programados enviados o fallidos que tengan más de 90 días de antigüedad, liberando así espacio.

Al final de todo, es dentro de la función **iniciar_cron()** que se llama una única vez desde el main donde se dejan registradas en memoria las tres tareas anteriores.

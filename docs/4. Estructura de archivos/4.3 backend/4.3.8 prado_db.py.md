Este archivo ubicado en `mocks/prado_db.py` es el encargado de simular una base de datos simulada para el moodle de Prado. Este script proporciona datos de pueba necesarios para que el panel funcione con normalidad durante el prototipo. 

En su interior lo único que se definen son una serie de variables JSON con infromación de profesores, usuarios, asignaturas etc. Algo equivalente a esto:

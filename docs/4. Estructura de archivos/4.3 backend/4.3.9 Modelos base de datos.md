Este directorio contiene todos los modelos de nuestra base de datos en PostgreSQL utilizando el ORM de SQLAlchemy. Cada archivo define un modelo de datos con sus columnas, tipos y restricciones.

A continuación definimos cada uno de los modelos y como se relacionan entre sí:
#### 1. Tabla: `sala_asignaturas` 

Almacena la jerarquía de espacios y salas creadas en Matrix para cada asignatura. De esta tabla cuelgan los horarios y los avisos.

- **Parámetros:**
	- **id** (int): Identificador primario.
	- **id_asignatura_prado** (String): Identificador de la asignatura en Prado
	- **id_matrix_sala** (String): El id de la sala en Matrix.
	- **alias_principal** (String): Nombre de la sala.
	- **descripcion** (String): Descripción de la sala.
	- **tipo** (enum): solo acepta 3 valores (espacio, sala o sala_avisos)
	- **id_padre** (string): Guarda el ID del espacio al que pertenece. SI es un espacio raíz almacena un valo nulo.
- **Relaciones:**
	- Relación 1 a 1 con **Cronograma**.
	- Relación 1 a N con **MensajeProgramado**.
	- **Borrado en Cascada:** Si una sala se elimina de esta tabla se destruye automáticamente su cronograma y sus mensajes programados.
#### 2. Tabla: `cronogramas`

Almacena la matriz de horarios de acceso para cada sala.

- **Parámetros:**
	- **id** (int): Identificador primario.
	- **sala_id** (Int): Foreing key que apunta al id de la tabla de **sala_asignaturas**.
	- **configuracion** (JSONB): Matriz de horarios 7x24 booleana. Al crearse se genera una totalmente abierta, es decir llena de 0.
- **Relaciones:**
	- Pertenece a una única **SalaAsignatura**.

#### 3. Tabla: `mensajes_programados`

Almacena la cola de mensajes programados.

- **Parámetros:**
    - **id** (int): Identificador primario.
    - **sala_id** (Int): Foreing key que apunta al id de la tabla de **sala_asignaturas**.
    - **contenido** (Text): El texto del mensaje.
    - **fecha_envio** (DateTime): El instante de tiempo en el que el mensaje debe publicarse.
    - **fecha_creacion** (DateTime): Fecha en la que se almacenó el mensaje.
    - **estado** (Enum): Controla el flujo con 3 estados posibles (pendiente, enviado, fallido)
- **Relaciones:** 
	- Pertenece a una única **SalaAsignatura**

#### 4. Tabla: `usuarios`

Almacena a los usuarios procesados por la aplicación. 

- **Parámetros:**
    
    - **id** (int): Identificador primario.
    - **correo** (String): Correo electrónico del estudiante.
    - **nombre** (String): Nombre y apellidos del estudiante.
    - **matrix_id** (String): Identificador del usuario en Matrix.
#### 5. Tabla: `logs_sistema`

Almacena un registro de las acciones que se han realizado en el sistema.

- **Parámetros:**
    
    - **id** (int): Identificador primario.
    - **contenido** (String): Mensaje de la acción ejecutada.
    - **fecha** (DateTime): Se genera automáticamente cuando se inserta un nuevo log.

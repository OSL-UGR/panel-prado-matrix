Este archivo, ubicado en `services/prado_api.py`, es el encargado de encapsular todas las comunicaciones con el la Moodle Prado de la UGR.


>⚠️ **Nota importante:** Las funciones actualmente leen de una base de datos estática y falsa (prado_db.py). En el momento en el que se integre la API definitiva de la universidad las **funciones de este archivo deberán de sobrescribirse** con las peticiones reales. Es importante que para un correcto funcionamiento se respete el nombre y el formato de los parámetros tanto de entrada como de salida.

A continuación mostramos el listado de las funciones que se definen en este archivo:

### Funciones con peticiones:

**`obtener_alumnos_prado_service()`**

- Recibe el ID de una asignatura (string). Busca en el catálogo y devuelve un diccionario con toda la información de la asignatura, incluyendo una lista con los datos de todos sus usuarios matriculados (profesores y alumnos). Si no existe, devuelve un diccionario de error.

**`obtener_total_asignaturas_usuario()`**

- Recibe el ID de Matrix de un Usuario (string). Recorre el catálogo de asignaturas comprobando en cuántas de ellas aparece ese usuario, devolviendo un entero con el conteo total.

**`obtener_total_usuarios_usuario()`**

- Recibe el ID de Matrix de un profesor (string). Calcula a cuántos alumnos da clase en total sumando los usuarios de todas sus asignaturas. Devuelve un número entero descartando duplicados (si un alumno está en dos asignaturas cuenta como uno).

**`obtener_asignaturas_usuario()`**

- Recibe el ID de Matrix de un usuario y la sesión de la bd local. Cruza la información de prado con nuestra bd para devolver una lista de diccionarios. Cada diccionario representa una asignatura del profesor e incluye un campo booleano de "sincronizada" que indica si la asignatura tiene ya creado su espacio en Matrix o no.

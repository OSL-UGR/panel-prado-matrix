La estructura de archivos del backend junto con el código fuente en el proyecto sigue la siguiente estructura. Este está desarrollado en Python bajo el framework de FastAPI.

Esta es la jerarquía exacta de archivos:

```bash
backend/
├── Dockerfile                # Instrucciones para Docker
├── requirements.txt          # Las dependencias que instalamos del proyecto
    ├── main.py               # El main donde lanzamos el servidor
    ├── api/
    │   └── routes.py         # Donde definimos todos los endpoints
    ├── core/
    │   ├── config.py         # Para cargar las variables de entorno
    │   └── database.py       # Establece conexión con la bd
    ├── mocks/
    │   └── prado_db.py       # Simulación de los datos de Prado
    ├── models/
    │   ├── cronogramas.py          # Tabla cronogramas de la bd
    │   ├── logs.py                 # Tabla logs de la bd
    │   ├── mensajes_programados.py # Tabla mensajes programados de la bd
    │   ├── sala_asignaturas.py     # Tabla sala asignaturas de la bd
    │   └── usuarios.py             # Tabla usuarios de la bd
    └── services/
        ├── cron_manager.py   # Controla las operaciones temporales (cron)
        ├── matrix_api.py     # Funciones que realizan peticiones a Matrix
        └── prado_api.py      # Funciones que realizan peticiones a Prado
```

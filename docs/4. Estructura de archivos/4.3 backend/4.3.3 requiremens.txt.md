Este archivo actúa como el inventario oficial de todas las librerías y paquetes de Python que el backend necesita para funcionar correctamente (como *FastAPI*, *SQLAlchemy*, *psycopg2*, etc.) con sus versiones exactas. Al ejecutar el comando:

``` bash
pip install -r requirements.txt
```

Así garantizamos que tanto el servidor como la máquina de cualquiera utilicen exactamente las mismas dependencias, evitando problemas de compatibilidad.

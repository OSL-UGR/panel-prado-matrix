
El directorio `pages/` contiene los componentes de React que representan cada una de las pantallas de la aplicación.

La funcionalidad y el flujo de tabajo de estos paneles ya ha siddo explicado en **3. Manual de Uso del Panel Prado-Matrix**. A nivel interno cada archivo de la carpeta es independiente, que se va insertando cuando el usuario navega. Estos se basan en:

1. **Memoria interna:** Utilizan _hooks_ de React (principalmente `useState`) para mantener en memoria temporal la información de la pantalla, como los datos que el usuario está escribiendo en un formulario, si un menú modal está abierto o cerrad etc.
2. **Conexión con el back:** Son los únicos componentes que importan y ejecutan las funciones del archivo `services/api.js`. Utilizan `useEffect` para pedir datos al backend nada más cargar la página, o lanzan peticiones de escritura y borrado cuando el usuario pulsa un botón.
3. **Renderizado Visual:** Despliegan todo el código JSX (HTML con clases de Tailwind CSS) específico para dibujar las tablas, botones, formulario etc de ese panel.

El directorio está compuesto por los siguientes archivos:

``` bash
.
├── CronogramaSalas.jsx
├── GestorSalas.jsx
├── Inicio.jsx
├── ProgramadorAvisos.jsx
└── RegistroLogs.jsx
```


Este archivo es la hoja de estilos global de la aplicación web. Su función principal es la de establecer unos estilos base a TailwindCSS para establecer una estética compartida.

En lugar de escribir CSS tradicional para cada botón o contenedor aquí se definen variables globales. Básicamente el script se divide en 3 partes:

**1º Definimos la paleta de colores:**

``` css
/* Definimos un tema personalizado general para nuestra app */
@theme {
	--color-fondo: #050505; /* Color fondo (negro)*/
	--color-paneles: #1A1A1A; /* Color para paneles (nego claro)*/
	--color-bordes: #A3A3A3; /*Color para bordes (gris)*/
	--color-texto: #EAEAEA; /* Color para texto (gris-blanco)*/
	--color-azul-turquesa: #00FFCC; /* Color para acentuar cosas (azul turquesa)*/
	--color-avisos: #FF8C00; /* Color para advertencias (naranja)*/
	--color-errores: #FF0000; /* Color para errores (rojo)*/
	
	/* Forzamos todos los tipos de letra a lo mismo*/
	--font-fuente: "Share Tech Mono", monospace, "Courier New";
	
	/* Para que aparezca una sombra desplazado abajo derecha de la caja principal*/
	--shadow-gris: 4px 4px 0px 0px var(--color-bordes); /* En gris */
	--shadow-azul: 4px 4px 0px 0px var(--color-azul-turquesa); /* EN turquesa */

}
```

**2º Definimos reglas específicas en el body como el fondo, la fuente etc:**

``` css 
body{

background-color: var(--color-fondo);
color: var(--color-texto);
font-family: var(--font-fuente);
-webkit-font-smoothing: antialiased; /* Hace que se vea más suave la fuente*/

/* Efecto de pantalla CRT antigua */
background-image: linear-gradient(
	rgba(255, 255, 255, 0.03) 1px,
	transparent 1px
);

background-size: 100% 4px;
}
```

Aquí se añade un fondo que en vez de ser el básico negro, añade una serie de barras muy minúsculas dándole a la aplicación un toque muy sutil de estilo.

**3º Personalizamos la barra de desplazamiento de la aplicación:**

``` css
/* Barra de scroll personalizada */
::-webkit-scrollbar {
	width: 12px;
}

::-webkit-scrollbar-track {
	background-color: var(--color-fondo);
	border-left: 1px solid var(--color-bordes);
}

::-webkit-scrollbar-thumb {
	background-color: var(--color-bordes);
}

::-webkit-scrollbar-thumb:hover {
	background-color: var(--color-azul-turquesa);
}
```

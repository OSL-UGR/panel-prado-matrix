La estructura de archivos del frontend junto con el código fuente en el proyecto sigue la siguiente estructura. Este está desarrollado utilizando React, empaquetado con Vite y usando los estlos de TailwindCSS.

``` bash
frontend/
├── Dockerfile                # Instrucciones para la imagen de Docker
├── package.json              # Las dependencias del proyecto Node.js
├── vite.config.js            # Configuración de red y plugins de Vite
├── index.html                # HTML base donde se inyecta la app
└── src/
    ├── main.jsx              # Punto de entrada de React
    ├── App.jsx               # Enrutador principal que decide qué vista cargar
    ├── index.css             # Hoja de estilos global de Tailwind
    ├── components/
    │   └── Layout.jsx        # Molde visual base para todas las vistas
    ├── pages/
    │   ├── Inicio.jsx            # Panel de inicio
    │   ├── GestorSalas.jsx       # Panel Gestor de Salas
    │   ├── ProgramadorAvisos.jsx # Panel Programador de avisos
    │   ├── CronogramaSalas.jsx   # Panel Cronograma de Salas
    │   └── RegistroLogs.jsx      # Panel Registro de logs
    └── services/
        └── api.js            # Comunicador con el backend (fetch)
```

Este archivo ubicado en `componentes/Layout.jsx` funciona como la plantilla principal de nuestra aplicación. En las Single Page Applications (SPA) no recargamos la web entera al cambiar de pestaña, lo que hacemos es mantener una  estructura fija sustituyendo el contenido central. Este componente es exactamente esa estructura fija.

A nivel de código y lógica el archivo se divide en tres partes:

**1. Header**

Al inicializarse el componente carga el `UseState` y `useEffect` propios de React para lanzar una petición automática al backend mediante la función `fetchPerfilUsuario()`. Mientras espera, se muestra un estado de "CONECTANDO...". y cuando recibe la respuesta se inserta el nombre y el ID de Matrix del profesor en un panel arriba a la derecha.

**2. Barra lateral con navegación**

La barra lateral se genera iterando sobre `paginasNavegables` que contiene las rutas de nuestra app. Las cuales ya estuvimos viendo dentro de `App.jsx`. Leemos el componente dado por la URL y redirijimos la información a este, aparte de resaltar con azul celeste el botón de la pestaña activa.

**3. Insertor de los paneles**

Gracias a la etiqueta de `<Outlet/>`, `App.jsx` inserta el código de las distintas páginas (Inicio, GestorSalas, RegistroLogs etc) dependiendo del botón que haya pulsado el usuario en la barra lateral.

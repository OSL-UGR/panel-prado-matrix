
Estos dos archivos trabajan en conjunto para inicializar el fronted y gestionar la navegación de la aplicación.

Por un lado, el archivo **main.jsx** es el punto de entrada de React. Aquí importamos los estilos globales (index.css), coge el componente raíz de la app y lo inyecta dentro del **index.html**. Tiene la siguiente forma:


``` JavaScript
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import './index.css'
import App from './App.jsx'

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

Por otro lado, el archivo **App.jsx** es el enrutador principal. SU trabajo consiste en leer la URL del navegador y decidir que página debe dibujarse en pantalla.

Como se ve en la estructura, se utiliza el componente "Layout" como envoltura del resto, garantizando así que los elementos como el menú lateral o la cabecera permanezcan fijos en la pantalla, mientras que el contenido central es el que cambia dinámicamente dependiendo de la ruta a la que acceda el usuario a través de los paneles de Inicio, GestorSalas, RegistroLogs etc. Tiene la siguiente forma:

``` JavaScript
// Enrutador de la aplicación
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import Layout from './components/Layout';  //Para envolver a todas las páginas y mantener el estilo común
import Inicio from './pages/Inicio';
import GestorSalas from './pages/GestorSalas';
import CronogramaSalas from './pages/CronogramaSalas';
import ProgramadorAvisos from './pages/ProgramadorAvisos';
import RegistroLogs from './pages/RegistroLogs';

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Layout />}> 
          <Route index element={<Inicio />} />          
          <Route path="salas" element={<GestorSalas />} />
          <Route path="avisos" element={<ProgramadorAvisos/>} />
          <Route path="horarios" element={<CronogramaSalas/>} />
          <Route path="logs" element={<RegistroLogs/>} />
        </Route>
      </Routes>
    </BrowserRouter>
  );
}
```



Este archivo contiene las instrucciones paso a paso que utiliza Docker para construir la imagen del frontend, como ya se explicó en el archivo de documentación "4.2 docker-compose.yml".

Básicamente, el script parte de una versión ligera de SO con Nose.js 22 (node::22-alpine). A continuación copia los archivos de configuración, ejecuta la instalación de las dependendencias para React y Vite mediante el comando `npm install`. Finalmente abre el puerto 5173 y define el comando de arranque para mantener nuestra aplicación web en ejecución y accesible desde el exterior.

Este archivo tiene la siguiente estructura:

``` Dockerfile
FROM node:22-alpine

WORKDIR /app

# Copiar los archivos de configuración y dependencias
COPY package.json package-lock.json* ./

# Instalar dependencias
RUN npm install

# Copiar el resto del código
COPY . .

# Exponer el puerto de Vite
EXPOSE 5173

# Comando para arrancar React (exponiendo al exterior con --host)
CMD ["npm", "run", "dev", "--", "--host", "0.0.0.0"]
```
